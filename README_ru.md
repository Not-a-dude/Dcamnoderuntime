# Dcam Node Runtime

*Читать на других языках: [English](README.md)*

Этот APK является непривилегированным хостом для выполнения Dcam Node ABI. Он намеренно не
запрашивает разрешений на доступ к интернету, камере, микрофону, чтению медиафайлов или хранилищу.

Runtime APK является обязательным. Dcam завершает проверку (handshake) ABI и UID перед открытием
`CameraDevice`. Отсутствие сервиса, отказ в привязке (binding), сбой Runtime или ошибка загрузки
стандартного узла (stock-node) приводит к закрытию Camera2 и выдаче явной ошибки камеры.
Предпросмотр (preview) и обработка фотографий никогда не откатываются (fallback) на процесс Dcam.

Каноничные ABI, AIDL, схемы, примеры, тесты совместимости и нормативные спецификации в формате
Markdown находятся в подмодуле [Dcam-Node-SDK](Dcam-Node-SDK).

Runtime компилирует AIDL и C-заголовок напрямую из этого SDK. Его загрузчик принимает файловые
дескрипторы (FD) модулей/зависимостей, разрешает только `dcam_node_get_api`, сериализует вызовы для
каждой сессии, передает `AHardwareBuffer*` без копирования пикселей, выводит предпросмотр через NDK
SurfaceControl и сообщает Dcam о состоянии буферов (release fences/dispositions).

Сборка отладочного APK для arm64:

```sh
./gradlew :app:assembleDebug
```
